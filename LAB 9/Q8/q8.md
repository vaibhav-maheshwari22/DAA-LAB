# Q8 — Minimum Number of Meeting Rooms

**File:** `q8.c`

## Problem

Given $n$ meeting intervals, each with a start time $s_i$ and end time $e_i$, find the minimum number of conference rooms needed so that no two meetings in the same room overlap. A meeting can start at the exact moment another ends (intervals closed at start, open at end).

## Input

- $n$ — number of meetings
- $n$ lines: `start end`

## Output

- Minimum number of rooms
- Room assignment for each input meeting

## Approach

Greedy sweep over meetings sorted by start time, combined with a **min-heap of active meeting end times**.

1. Sort meetings by start time.
2. Maintain a min-heap of currently active meetings keyed by end time.
3. For each meeting in order:
   - Pop every active meeting whose end time is $\le$ the current start time — those rooms are now free.
   - If a freed room exists, reuse it; otherwise open a new room.
   - Push the current meeting's end time into the heap.

Formally, at meeting $i$ with start $s_i$:

$$
\text{while } \text{heap.top}() \le s_i: \quad \text{freed\_room} \gets \text{heap.pop}()
$$

$$
\text{assigned}[i] =
\begin{cases}
\text{freed\_room} & \text{if a room was freed} \\
\text{new room} & \text{otherwise}
\end{cases}
$$

The number of rooms opened is the answer.

### Why this is optimal

The number of rooms needed at any moment equals the maximum number of simultaneously active meetings. Sorting by start ensures we process meetings in the order they begin; the heap ensures we release rooms as soon as they become free. The peak heap size across the sweep is exactly the answer.

## Complexity

- **Time:** $O(n \log n)$ — sort dominates, plus $O(n \log n)$ heap operations
- **Space:** $O(n)$ — meeting list, heap, and assignment arrays

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q8.c -o q8
./q8
```

## Sample

Input:

```
3
0 30
5 10
15 20
```

Output:

```
Minimum rooms: 2
Meeting room assignments:
1 1
2 2
3 2
```

### Walk-through

| Step | Meeting | Action | Active heap | Rooms used |
|:---:|:-------:|:-------|:------------|:----------:|
| 1 | `(0, 30)` | open room 1 | `[30:1]` | 1 |
| 2 | `(5, 10)` | $5 < 30$, open room 2 | `[10:2, 30:1]` | 2 |
| 3 | `(15, 20)` | pop `10` (freed), reuse room 2 | `[20:2, 30:1]` | 2 |

Peak simultaneous meetings = 2, so **minimum rooms = 2**.
