# Q4 — Minimum Cost to Connect Sticks

**File:** `q4.c`

## Problem

Given $n$ sticks of non-negative lengths, repeatedly join two sticks. Joining sticks of lengths $x$ and $y$ costs $x + y$ and produces one stick of length $x + y$. Find the minimum total cost to end up with one stick, and print each merge operation.

## Input

- $n$ — number of sticks
- $n$ non-negative stick lengths

## Output

- Minimum total cost
- Each merge as `first second result`

## Approach

Greedy: always merge the two shortest sticks first. This is the same exchange argument as Huffman coding — short sticks should be merged many times, long sticks as few times as possible.

Use a min-heap of current stick lengths. At each step:

$$
\text{cost} \gets \text{cost} + (x + y), \quad \text{where } x, y = \text{two smallest sticks}
$$

Then insert $(x + y)$ back into the heap. Repeat $n - 1$ times.

Total cost across all merges:

$$
\text{total} = \sum_{k=1}^{n-1} \left( x_k + y_k \right)
$$

Recording each merge in a `trace[]` array lets us print the exact sequence.

## Complexity

- **Time:** $O(n \log n)$ — one heap op per merge
- **Space:** $O(n)$ — heap plus trace of merges

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q4.c -o q4
./q4
```

## Sample

Input:

```
4
2 4 3 5
```

Output:

```
Minimum cost: 28
Merges (first, second, result):
2 3 5
4 5 9
5 9 14
```

Step-by-step:
- Merge 2 and 3 → cost 5, sticks now $\{4, 5, 5\}$
- Merge 4 and 5 → cost 9, sticks now $\{5, 9\}$
- Merge 5 and 9 → cost 14, one stick left
- Total = $5 + 9 + 14 = \mathbf{28}$
