# Q7 — Minimise Deviation in Array

**File:** `q7.c`

## Problem

Given an array $A = [a_0, a_1, \ldots, a_{n-1}]$ of $n$ positive integers, we are allowed two operations any number of times:

1. **Double** any odd element: $a_i \gets 2 a_i$
2. **Halve** any even element: $a_i \gets a_i / 2$

The **deviation** of the array is defined as:

$$
\text{deviation} = \max(A) - \min(A)
$$

Minimise the deviation and print the trace plus the final array.

## Input

- $n$ — array size
- $n$ positive integers

## Output

- Trace of `(step, maximum, minimum, deviation)` at each step
- Minimum deviation achieved
- Final array

## Approach

### Step 1 — Normalise odd values

Any odd value $a_i$ can be doubled to $2a_i$, producing an even number. Since doubling an odd value is always allowed (and any even value can later be halved back), we start by **doubling every odd element once**. This gives a single baseline:

$$
a_i \gets
\begin{cases}
2 a_i & \text{if } a_i \text{ is odd} \\
a_i & \text{otherwise}
\end{cases}
$$

### Step 2 — Greedy halving of the current maximum

After normalisation, only halving even values makes sense — doubling would only increase the range. So we:

1. Compute the current deviation.
2. If the maximum is even, halve it and repeat.
3. If the maximum is odd, stop — it cannot be halved further.

Formally, at each step:

$$
\text{best} \gets \min\left(\text{best},\ \max(A) - \min(A)\right)
$$

$$
\text{if } \max(A) \text{ is even: } \max(A) \gets \frac{\max(A)}{2}
$$

Halving the maximum is optimal because only the maximum can reduce the deviation. Any other change would either increase the max or decrease the min in a way that does not shrink the range.

## Complexity

- **Time:** $O(n \log M \log n)$ — up to $O(n \log M)$ heap updates, each costing $O(\log n)$
- **Space:** $O(n)$ — heap plus current values array

Here $M = \max_i a_i$ is the largest initial value.

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q7.c -o q7
./q7
```

## Sample

Input:

```
4
1 2 3 4
```

Output:

```
Trace (step, maximum, minimum, deviation):
0 6 2 4
1 4 2 2
2 3 2 1
Minimum deviation: 1
Final array: 2 2 3 2
```

### Walk-through

1. **Initial normalisation** (odd values doubled):
   - $1 \to 2$, $2 \to 2$, $3 \to 6$, $4 \to 4$
   - Array: $[2, 2, 6, 4]$, max $= 6$, min $= 2$, deviation $= 4$

2. **Step 1** — halve max $6 \to 3$:
   - Array: $[2, 2, 3, 4]$, max $= 4$, min $= 2$, deviation $= 2$

3. **Step 2** — halve max $4 \to 2$:
   - Array: $[2, 2, 3, 2]$, max $= 3$, min $= 2$, deviation $= 1$

4. **Stop** — max $3$ is odd, cannot halve further.

Minimum deviation = **1**.
