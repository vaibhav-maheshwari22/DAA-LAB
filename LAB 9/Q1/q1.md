# Q1 — Fractional Knapsack with Deterioration Rate

**File:** `q1.c`

## Problem

We have $n$ items. Each item has value $v$, weight $w$, and decay rate $\lambda > 0$. If we start consuming item $i$ at time $t$ (where $t$ = total weight consumed so far), its density is:

$$
\text{density}_i(t) = \frac{v_i}{w_i} - \lambda_i \cdot t
$$

Fill a knapsack of capacity $W$ with fractions of items to maximize total value. We also choose the order of consumption.

## Approach

Consuming `amount` units of item $i$ starting at time $t$ gives:

$$
\text{value} = \frac{v_i}{w_i} \cdot \text{amount} - \lambda_i \cdot \left( t \cdot \text{amount} + \frac{\text{amount}^2}{2} \right)
$$

At most one item ends up partially consumed, so we do subset DP over all $2^n$ masks of fully consumed items, and try adding one partial item at the end.

For each mask $m$ and each unused item $j$, with $t = \text{weight}[m]$:

$$
\text{Option A: } \text{best} = \max\left(\text{best},\ \text{dp}[m]\right)
$$

$$
\text{Option B: } \text{amt} = \min\left(w_j,\ W - t\right)
$$

$$
\text{best} = \max\left(\text{best},\ \text{dp}[m] + \frac{v_j}{w_j} \cdot \text{amt} - \lambda_j \cdot \left( t \cdot \text{amt} + \frac{\text{amt}^2}{2} \right)\right)
$$

$$
\text{Option C (if } t + w_j \le W \text{): } \text{dp}[m \mid 2^j] = \max\left(\text{dp}[m \mid 2^j],\ \text{dp}[m] + v_j - \lambda_j \cdot \left( t \cdot w_j + \frac{w_j^2}{2} \right)\right)
$$

Reconstruction uses `parent[]` and `picked[]` arrays.

## Complexity

- **Time:** $O(n \cdot 2^n)$
- **Space:** $O(2^n)$

Only feasible for small $n$ (capped at 20).

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q1.c -o q1
./q1
```

## Sample

Input:

```
2 3
10 2 0
12 3 0
```

Output:

```
Maximum value: 14.000000
Schedule (item index, weight consumed):
  item 1 : 2.000000
  item 2 : 1.000000  (fractional)
```

Take all of item 1 (weight 2, value 10), then 1 unit of item 2 (value 4). Total = 14.

## Note

The DP assumes the partial item always comes last. Most cases work, but not all.

Counterexample:
- Item A: $v = 20,\ w = 10,\ \lambda = 0.5$
- Item B: $v = 20,\ w = 10,\ \lambda = 0.1$
- $W = 15$

Optimal is 2 units of A first, then 10 units of B → 16. This DP finds 15.

# Q2 — Huffman Coding

**File:** `q2.c`

## Problem

Given $n$ symbols with positive frequencies, build a minimum-length prefix code. Print the **canonical** codebook sorted by code length and symbol.

## Approach

1. **Build Huffman tree**: put all symbols into a min-heap keyed by frequency. Repeatedly pop the two smallest, merge into an internal node, push back. Ties are broken by index so the shape is deterministic.
2. **Get code lengths**: DFS from the root; a leaf's depth is its code length. If a symbol ends up at depth 0 (i.e. only one symbol), its length is 1.
3. **Canonicalize**: sort leaves by $(\text{length}, \text{symbol})$. Assign codes as:
   - first code = all zeros of its length
   - next code = previous + 1 in binary
   - if length increases, right-pad with zeros

The Huffman merge rule at each step:

$$
\text{parent.freq} = \text{freq}[a] + \text{freq}[b]
$$

where $a$ and $b$ are the two minimum-frequency nodes.

Canonical assignment for consecutive sorted codes:

$$
\text{code}[i] =
\begin{cases}
\underbrace{00\ldots0}_{L_i} & \text{if } i = 0 \\[6pt]
\text{binary}\left(\text{code}[i-1] + 1\right) & \text{otherwise, right-padded to } L_i
\end{cases}
$$

This produces a codebook that's trivially decodable without transmitting the tree.

## Complexity

- **Time:** $O(n \log n)$ — heap operations dominate
- **Space:** $O(n)$ — tree, heap, codebook

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q2.c -o q2
./q2
```

## Sample

Input:

```
3
a 5
b 2
c 1
```

Output:

```
Symbol Length CanonicalCode
a 1 0
b 2 10
c 2 11
```

Tree: `a` (freq 5) merges last with `bc` (freq 3). Length of `a` = 1, lengths of `b`, `c` = 2. Canonical order by $(\text{length}, \text{symbol})$: `a`, `b`, `c`. Codes: `0`, `10`, `11`.
