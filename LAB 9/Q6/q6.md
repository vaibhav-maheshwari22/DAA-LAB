# Q6 — Reorganise String with K-Distance Apart

**File:** `q6.c`

## Problem

Given a string $S$ of length $n$ and an integer $K \ge 0$, rearrange the characters of $S$ so that the same character appears at least $K$ positions apart. If no such rearrangement exists, output an empty string.

## Input

- Integer $K$
- String $S$ (whitespace-delimited)

## Output

- A valid rearrangement, or an empty string if impossible
- Position-by-position trace of the arrangement

## Approach

Greedy placement, one position at a time. At each position $i$, we look for the character that:

1. still has remaining count $> 0$, and
2. hasn't been used in the last $K - 1$ positions, i.e. $i - \text{last}[c] \ge K$, and
3. has the **largest remaining count** among all such characters.

If no character satisfies all three conditions at some position, the arrangement is impossible.

Formally, at position $i$:

$$
\text{best} = \arg\max_{c}\ \left\{ \text{count}[c] \ \middle|\ \text{count}[c] > 0 \ \wedge \ i - \text{last}[c] \ge K \right\}
$$

Then we place `best`, decrement `count[best]`, and set `last[best] = i`.

### Why highest count first?

The character with the highest remaining count is the one most likely to become "stuck" if we delay it. Placing it as early as possible (subject to the cooldown) gives the most flexibility for later positions. This is the same exchange argument used in Huffman and task-scheduling greedy algorithms.

## Complexity

- **Time:** $O(n \cdot 256)$ — for each of the $n$ positions, we scan all 256 possible character values
- **Space:** $O(n + 256)$ — the result buffer plus `count[]` and `last[]` arrays

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q6.c -o q6
./q6
```

## Sample

Input:

```
3
aabbcc
```

Output:

```
Rearranged string: abcabc
Position trace:
  pos  0 : a
  pos  1 : b
  pos  2 : c
  pos  3 : a
  pos  4 : b
  pos  5 : c
```

Walk-through with $K = 3$:

| pos | picked | reason |
|:---:|:------:|:-------|
| 0 | `a` | tie between `a`, `b`, `c` — first one wins |
| 1 | `b` | tie between `b`, `c` — first one wins |
| 2 | `c` | only `c` remains with gap check OK |
| 3 | `a` | `i - last[a] = 3 \ge K`, so `a` is available |
| 4 | `b` | `i - last[b] = 3 \ge K`, so `b` is available |
| 5 | `c` | `i - last[c] = 3 \ge K`, so `c` is available |

Each repeated character is exactly $3$ positions apart — the minimum allowed.

## Impossible case

If at any position no valid character exists, we print an empty string. For example:

```
Input:
2
aa

Output:
Rearranged string: 
```

With $K = 2$, the two `a`'s must be at least 2 apart, but the string only has length 2 — impossible.
