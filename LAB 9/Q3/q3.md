# Q3 — Minimum Refuelling Stops

**File:** `q3.c`

## Problem

A vehicle starts at the origin with `fuel` litres and must reach distance $D$. There are $n$ stations along the way, each at distance $d_i$ with $f_i$ fuel available. Find the minimum number of refuelling stops, or report impossible.

## Input

- `D F n` — target distance, initial fuel, number of stations
- $n$ lines: `distance fuel`

## Output

- `Minimum stops: K` and the chosen station IDs (in input order)
- or `Impossible` if the target cannot be reached

## Approach

Sweep the stations in increasing distance. Whenever `fuel` is not enough to reach the next point, refuel from the **largest fuel amount among the stations we've already passed** — a max-heap handles this in $O(\log n)$.

This greedy is optimal: picking the biggest available refuel never hurts, it only delays the next refuel decision.

Steps:

1. Sort stations by distance.
2. Walk through stations in order, adding each passed station's fuel to a max-heap.
3. Before moving to the next point, if $\text{fuel} < \text{gap}$, pop the largest fuel from the heap and add it — one stop.
4. If the heap empties before we can move, the trip is impossible.

Formally, at each stage:

$$
\text{fuel} \gets \text{fuel} + \max_{s \in \text{passed}} f_s \quad \text{while } \text{fuel} < \text{gap}
$$

## Complexity

- **Time:** $O(n \log n)$ — sort plus heap operations
- **Space:** $O(n)$ — station list, heap, chosen list

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q3.c -o q3
./q3
```

## Sample

Input:

```
25 10 3
10 10
14 5
20 10
```

Output:

```
Minimum stops: 2
Stops (station IDs): 1 3
```

Start with 10 fuel. Drive to station 1 at distance 10, fuel hits 0. Refuel 10 → 10 fuel. Continue past station 2 (skip), reach station 3 at distance 20 with fuel 0, refuel 10. Reach 25 with 5 fuel left. Total stops = 2 (stations 1 and 3).
