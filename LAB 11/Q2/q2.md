# Q2 — Multi-Source BFS for Radius-Constrained Voronoi Partitioning

**File:** `q2.c`

## Problem
Given an unweighted graph with $K$ hub vertices and a radius threshold $R$, assign each vertex to the closest hub. If the minimum distance to any hub exceeds $R$, the vertex is unassigned ($\text{owner} = -1$). Ties are broken by the smallest hub index.

## Input
- First line: $V\ E\ K\ R$.
- Second line: $K$ integers representing the hubs.
- Next $E$ lines: $u\ v$ (undirected edges).

## Output
- For each vertex: assigned hub index and distance (or `-1` if unassigned).

## Approach
We perform a **Multi-Source BFS** initialized with all $K$ hubs at distance $0$. The BFS queue stores `(vertex, owner)`. 
When visiting a neighbor $v$ from $u$:
1. If $v$ is unvisited, assign $\text{dist}[v] = \text{dist}[u] + 1$ and propagate $u$'s owner.
2. If $v$ has the same distance but a larger owner index, update its owner to the smaller index.
Finally, if $\text{dist}[v] > R$, mark it unassigned.
$$
\text{owner}[v] = \arg\min_{i} \{ \text{dist}(h_i, v) \}
$$

## Complexity
- **Time:** $O(V + E)$ — every vertex and edge is processed at most once.
- **Space:** $O(V + E)$ — adjacency list and queue storage.
