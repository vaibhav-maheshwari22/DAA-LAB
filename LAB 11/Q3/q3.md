# Q3 — Bidirectional BFS for Shortest Transformation Sequence

**File:** `q3.c`

## Problem
Given a dictionary of $N$ words of length $L$, a start word $A$, and a target word $B$, find the minimum number of single-character mutations to transform $A$ into $B$. All intermediate words must exist in the dictionary.

## Input
- First line: $N\ L$.
- Second line: $A\ B$.
- Next $N$ lines: dictionary words.

## Output
- The minimum number of mutations, or `-1` if no path exists.

## Approach
We use **Bidirectional BFS** to explore from both $A$ and $B$ simultaneously, expanding the smaller queue at each step. 
Since $N \le 10^5$, we must use **Binary Search** (`bsearch`) over the sorted dictionary to achieve $O(\log N)$ lookup time. For each word, we generate all possible mutations (Hamming distance 1) on the fly. If a word is visited by both the forward and backward BFS, the shortest path length is:
$$
\text{answer} = \text{dist}_{\text{forward}}[v] + \text{dist}_{\text{backward}}[v]
$$

## Complexity
- **Time:** $O(N \log N + N \cdot L \cdot 26 \cdot \log N)$ — sorting and BFS with binary search.
- **Space:** $O(N)$ — storing the dictionary and distance arrays.
