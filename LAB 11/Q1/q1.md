# Q1 — Shortest Path on Parity-Constrained Graphs

**File:** `q1.c`

## Problem
Given a directed graph with edge weights $w(u,v) \in \{0,1\}$, an extra penalty $C \ge 0$, and a source $S$. Find the minimum effective cost to all vertices, where the cost of a path $P$ is $W(P) + C \cdot k_1(P)$, with $W(P)$ being the sum of weights and $k_1(P)$ the number of weight-1 edges.

## Input
- First line: $V\ E\ S\ C$.
- Next $E$ lines: $u\ v\ w$ (edge from $u$ to $v$ with weight $w \in \{0,1\}$).

## Output
- For each vertex: minimum cost from $S$, or `Unreachable`.

## Approach
Since the weights are $0$ and $1$, the effective cost of traversing an edge is:
$$
\text{cost}(u,v) = \begin{cases} 
0 & \text{if } w = 0 \\ 
1 + C & \text{if } w = 1 
\end{cases}
$$
This is a shortest path problem with only two edge weights: $0$ and $1+C$. We can solve it using a **0-1 BFS** (using a double-ended queue / deque). 
When we relax an edge:
- If the effective cost is $0$, we push the neighbor to the **front** of the deque.
- If the effective cost is positive ($1+C$), we push it to the **back**.
This guarantees that the deque is always sorted by distance, achieving $O(V+E)$ time.

## Complexity
- **Time:** $O(V + E)$ — each vertex and edge is processed at most once.
- **Space:** $O(V + E)$ — adjacency list, distance array, and deque.
