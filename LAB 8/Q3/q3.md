# 🔤 Q3 — Longest Common Subsequence

![File](https://img.shields.io/badge/file-q3__lcs.c-blue)
![Time](https://img.shields.io/badge/Time-O(m·n)-orange)
![Space](https://img.shields.io/badge/Space-O(m·n)-green)

> **Goal:** Find the length of the longest common subsequence of two strings, and **reconstruct** the actual subsequence.

---

## 📥 Input

- String `X` (length `m`)
- String `Y` (length `n`)

## 📤 Output

- 2D DP table
- LCS length
- Reconstructed LCS string

---

## 🧠 Approach

Classic **2D DP**:

```text
if X[i-1] == Y[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = max( dp[i-1][j], dp[i][j-1] )
