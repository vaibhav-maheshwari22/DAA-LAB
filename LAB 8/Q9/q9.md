> **Goal:** Simulate the Collatz trajectory until reaching `1`, for a single value or across an interval `[a, b]`.  
> **Bonus:** This is an **open problem** in mathematics — nobody has proven it yet! 🔥

---

## 📥 Input

Menu-driven:
- **Mode 1** — single starting number `n`
- **Mode 2** — interval bounds `a`, `b`

## 📤 Output

| Mode | What you get |
|:----:|:-------------|
| 1 | Full trajectory, step count, peak value |
| 2 | Per-number stats + interval summary (max length, highest peak) |

---

## 🧠 Approach

The recurrence is beautifully simple:

```text
T(n) = n / 2      if n is even
T(n) = 3n + 1     if n is odd
Stop when n == 1
