# 🪙 Q2 — Coin Change: Total Number of Ways

![File](https://img.shields.io/badge/file-q2__coin__ways.c-blue)
![Time](https://img.shields.io/badge/Time-O(n·V)-orange)
![Space](https://img.shields.io/badge/Space-O(V)-green)

> **Goal:** Count **distinct combinations** that sum to `V`. Order doesn't matter — `1+2` and `2+1` are the same.

---

## 📥 Input

| Symbol | Meaning |
|:------:|:--------|
| `n` | Distinct coin denominations |
| `coins[]` | Array of values |
| `V` | Target amount |

## 📤 Output

- DP table state (amount → number of ways)
- Total combinations

---

## 🧠 Approach

**1D DP**. The trick is the **loop order**:

```text
for each coin c:
    for j = c .. V:
        dp[j] += dp[j - c]
