# 📈 Q4 — Longest Increasing Subsequence

![File](https://img.shields.io/badge/file-q4__lis.c-blue)
![Time](https://img.shields.io/badge/Time-O(n²)-orange)
![Space](https://img.shields.io/badge/Space-O(n)-green)

> **Goal:** Find the length of the longest **strictly increasing** subsequence, and reconstruct it.

---

## 📥 Input

- `n` — array size
- Array `A[0..n-1]`

## 📤 Output

- DP table state
- LIS length
- Reconstructed subsequence

---

## 🧠 Approach

**1D DP** — for each element, check every earlier element:

```text
dp[i] = 1 + max( dp[j] )    for all j < i with A[j] < A[i]
