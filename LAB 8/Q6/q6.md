# ✏️ Q6 — Edit Distance with Traceback

![File](https://img.shields.io/badge/file-q6__edit__distance.c-blue)
![Time](https://img.shields.io/badge/Time-O(m·n)-orange)
![Space](https://img.shields.io/badge/Space-O(m·n)-green)

> **Goal:** Find the minimum insert / delete / substitute operations to convert string `A` into string `B`, and print **every step** of the transformation.

---

## 📥 Input

- String `A` (length `m`)
- String `B` (length `n`)

## 📤 Output

- 2D DP table
- Minimum edit distance
- Step-by-step operations (Keep / Insert / Delete / Substitute)

---

## 🧠 Approach

**2D DP** — three operations per cell:

```text
if A[i-1] == B[j-1]:
    dp[i][j] = dp[i-1][j-1]                    // no cost
else:
    dp[i][j] = 1 + min( dp[i-1][j],            // delete
                        dp[i][j-1],            // insert
                        dp[i-1][j-1] )         // substitute
