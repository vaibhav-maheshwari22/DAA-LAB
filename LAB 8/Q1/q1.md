> **Goal:** Given coin denominations and a target amount `V`, find the **minimum number of coins** needed. Return `-1` if it's impossible.

---

## 📥 Input

| Symbol | Meaning |
|:------:|:--------|
| `n` | Number of coin denominations |
| `coins[]` | Array of `n` coin values |
| `V` | Target amount |

## 📤 Output

- DP table state (amount → min coins)
- Coins used (traceback)
- Final answer, or `-1`

---

## 🧠 Approach

Standard **1D DP**. For each amount, try every coin and pick the best.
