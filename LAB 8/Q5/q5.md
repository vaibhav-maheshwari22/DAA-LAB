# 💰 Q5 — Maximum Sum Increasing Subsequence

![File](https://img.shields.io/badge/file-q5__msis.c-blue)
![Time](https://img.shields.io/badge/Time-O(n²)-orange)
![Space](https://img.shields.io/badge/Space-O(n)-green)

> **Goal:** Find the maximum possible **sum** of a strictly increasing subsequence, and reconstruct the elements.

---

## 📥 Input

- `n` — array size
- `n` positive integers `A[0..n-1]`

## 📤 Output

- DP table state
- Maximum sum
- Subsequence giving that sum

---

## 🧠 Approach

Same skeleton as LIS, but we track **sum instead of length**:

```text
msis[i] = A[i] + max( msis[j] )    for all j < i with A[j] < A[i]
