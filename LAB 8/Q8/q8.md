# 🌳 Q8 — Optimal Binary Search Tree

![File](https://img.shields.io/badge/file-q8__obst.c-blue)
![Time](https://img.shields.io/badge/Time-O(n³)-orange)
![Space](https://img.shields.io/badge/Space-O(n²)-green)

> **Goal:** Find the BST with the **minimum expected search cost** for `n` sorted keys with probabilities `p[1..n]` and `n+1` dummy keys with probabilities `q[0..n]`.

---

## 📥 Input

| Symbol | Meaning |
|:------:|:--------|
| `n` | Number of real keys |
| `p[1..n]` | Successful search probabilities |
| `q[0..n]` | Unsuccessful (dummy) search probabilities |

## 📤 Output

- Expected cost table `e[i][j]`
- Optimal root table `root[i][j]`
- Minimum expected cost
- Full BST structure with dummy keys

---

## 🧠 Approach

Classic **CLRS 3-loop DP**:

```text
w[i][j] = w[i][j-1] + p[j] + q[j]

e[i][j] = min over r ∈ [i, j] of:
              e[i][r-1] + e[r+1][j] + w[i][j]
