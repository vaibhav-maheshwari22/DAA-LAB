# 🪵 Q7 — Rod Cutting with Reconstruction

![File](https://img.shields.io/badge/file-q7__rod__cutting.c-blue)
![Time](https://img.shields.io/badge/Time-O(n²)-orange)

> **Goal:** Given rod length `n` and prices per piece, find the **maximum revenue** and the exact **piece lengths** that produce it.

---

## 📥 Input

- `n` — rod length
- `price[0..n-1]` — `price[i-1]` = price of a piece of length `i`

## 📤 Output

- DP table state
- Max revenue
- Optimal piece lengths

---

## 🧠 Approach

**1D DP** — try every first cut:

```text
revenue[j] = max( price[i-1] + revenue[j-i] )    for 1 ≤ i ≤ j
