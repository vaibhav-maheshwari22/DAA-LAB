# Question 7: Matrix Chain Multiplication (MCM)

## Problem Statement
Given a chain of $n$ matrices $\langle A_1, A_2, \dots, A_n \rangle$ where matrix $A_i$ has dimensions $p_{i-1} \times p_i$, find the optimal parenthesization that minimizes the total number of scalar multiplications, and print the resulting order.

---

## Algorithm & Mathematical Formulation

### 1. Optimal Substructure
Let $m[i][j]$ be the minimum number of scalar multiplications needed to compute the matrix product $A_i \dots A_j$.
If we partition the chain at split point $k$ ($i \le k < j$), the total cost is:
* Cost of computing $A_i \dots A_k \implies m[i][k]$
* Cost of computing $A_{k+1} \dots A_j \implies m[k+1][j]$
* Cost of multiplying the two resulting matrices $\implies p_{i-1} \cdot p_k \cdot p_j$

### 2. Recurrence Relation
$$m[i][j] = \begin{cases}
0, & \text{if } i = j \\
\min_{i \le k < j} \big(m[i][k] + m[k+1][j] + p_{i-1}p_k p_j\big), & \text{if } i < j
\end{cases}$$

### 3. Parenthesization Table
An auxiliary table $s[i][j]$ records the split index $k$ that achieves the minimum cost:
$$s[i][j] = \arg\min_{i \le k < j} \big(m[i][k] + m[k+1][j] + p_{i-1}p_k p_j\big)$$
The optimal parenthesization string is reconstructed recursively using $s[i][j]$.

---

## Complexity Analysis
* **Time Complexity:** $\Theta(n^3)$. Filling the upper-triangular table requires evaluating chains of length $2$ through $n$, scanning over all intermediate split positions $k$ for each subproblem.
* **Space Complexity:** $\Theta(n^2)$ auxiliary memory to store both the cost table $m[i][j]$ and the split table $s[i][j]$.
