# Question 2: Super Egg Testing Experiment

## Problem Statement
A firm wants to determine the highest floor in a 100-storey building from which a super-strong egg can fall without breaking[cite: 2]. Given two identical eggs, determine the minimum number of droppings guaranteed to find the critical threshold in all cases[cite: 2]. Design and implement a generalized dynamic programming solution for $E$ eggs and $F$ floors, and derive its complexity[cite: 2].

---

## Algorithm & Mathematical Formulation

### 1. Two-Egg 100-Floor Classical Case
For 2 eggs and 100 floors, we balance linear scanning against binary search by decreasing step sizes:
$$x + (x - 1) + (x - 2) + \dots + 1 \ge 100$$
$$\frac{x(x + 1)}{2} \ge 100 \implies x = 14$$
Thus, 14 drops are required in the worst case.

### 2. Generalized DP Formulation
Let $dp[i][j]$ be the minimum number of attempts needed in the worst case with $i$ eggs and $j$ floors[cite: 2].

If we drop an egg from floor $k$ ($1 \le k \le j$):
* **Egg Breaks:** We now have $i - 1$ eggs left, and we must test the $k - 1$ floors below floor $k \implies dp[i-1][k-1]$.
* **Egg Survives:** We still have $i$ eggs left, and we must test the remaining $j - k$ floors above floor $k \implies dp[i][j-k]$.

Since the adversary chooses the worst outcome, we take the maximum of both possibilities. We choose the optimal floor $k$ to minimize this worst case:
$$dp[i][j] = 1 + \min_{1 \le k \le j} \Big( \max\big(dp[i-1][k-1],\, dp[i][j-k]\big) \Big)$$

### 3. Base Conditions
* $dp[1][j] = j$ (with 1 egg, we must test floors sequentially from bottom to top).
* $dp[i][0] = 0$ (0 floors require 0 drops).
* $dp[i][1] = 1$ (1 floor requires 1 drop for any positive number of eggs).

---

## Complexity Analysis
* **Time Complexity:** $O(E \cdot F^2)$ where $E$ is the number of eggs and $F$ is the number of floors. Filling an $E \times F$ DP table requires a linear search over $j$ potential drop positions for each state.
* **Space Complexity:** $O(E \cdot F)$ auxiliary memory to store the 2D DP tabulation matrix.
