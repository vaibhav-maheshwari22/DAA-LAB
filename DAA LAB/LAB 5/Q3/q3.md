# Question 3: Quick Sort with File I/O

## Problem Statement
Implement Quick sort of N random elements stored in a file.

## Approach & Features
1. **Random Generation:** The program uses `rand()` to generate $N$ random integers and writes them to `input_qs.txt`.
2. **File Reading:** The numbers are read back into dynamically allocated memory.
3. **Quick Sort:** The standard recursive Quick Sort algorithm (using Lomuto partition) is applied to sort the array in-place.
4. **Validation:** A dedicated `validate_sort()` function iterates through the processed array to strictly ensure $A[i] \le A[i+1]$ for all elements, dynamically discharging the correctness proof.
5. **Output Export:** The validated sorted array is successfully written to `output_qs.txt`.

## Complexity Analysis
* **Time Complexity:** 
  * **Best & Average Case:** $O(N \log N)$ (when the pivot splits the array evenly).
  * **Worst Case:** $O(N^2)$ (occurs if the array is already sorted and the pivot is strictly the smallest/largest element).
* **Space Complexity:** $O(\log N)$ expected stack space due to recursion.
