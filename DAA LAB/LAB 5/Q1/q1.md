# Question 1: Find Median Without Sorting

## Problem Statement
Find the median of a list of N numbers without sorting the list. Do the complexity analysis of your algorithm.

## Approach & Features
1. **Quickselect Algorithm:** Instead of fully sorting the array in $O(N \log N)$ time, we use the Quickselect algorithm (based on Quicksort's Lomuto partition).
2. **Target Index:** The median of an array of size $N$ is located at index $N/2$ (using 0-based indexing). 
3. **Selective Recursion:** The algorithm partitions the array around a pivot. If the pivot's final index is exactly $N/2$, we return it. If the pivot index is greater, we recurse only on the left subarray; if smaller, only on the right.
4. **Manual Validation:** The program accepts manual integer inputs from the user to strictly validate specific test cases.

## Complexity Analysis
* **Time Complexity:** 
  * **Average & Best Case:** $O(N)$. Since we only recurse into one half of the partitioned array, the recurrence relation is $T(N) = T(N/2) + O(N)$, which mathematically resolves to strictly $O(N)$.
  * **Worst Case:** $O(N^2)$. This occurs if the array is already sorted or reverse-sorted, and the partition consistently picks the absolute maximum or minimum element as the pivot, leading to $T(N) = T(N-1) + O(N)$.
* **Space Complexity:** $O(1)$ auxiliary space. The algorithm partitions the array in-place. The recursive stack trace takes $O(\log N)$ on average, and $O(N)$ space in the absolute worst case.
