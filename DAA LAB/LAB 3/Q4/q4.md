# Question 4: Matrix Multiplication using Strassen's Method

## Problem Statement
Write a C program to multiply two square matrices of size $n \times n$ using Strassen’s method and validate its time complexity using the divide and conquer approach.

---

## Theoretical Justification & Algorithm

### The Naive Approach
A standard matrix multiplication of two $n \times n$ matrices involves 3 nested loops. When viewed recursively, it divides the matrices into 4 sub-matrices of size $n/2 \times n/2$ and makes **8 recursive multiplications**.
* **Recurrence Relation:** $T(n) = 8T(n/2) + O(n^2)$
* **Time Complexity:** $O(n^3)$

### Strassen's Divide and Conquer Approach
Strassen's algorithm is an optimization that reduces the number of recursive multiplications from 8 to **7**. It achieves this by creating 7 intermediate matrices ($M_1$ to $M_7$) using a clever combination of matrix additions and subtractions.

$$M_1 = (A_{11} + A_{22})(B_{11} + B_{22})$$
$$M_2 = (A_{21} + A_{22})B_{11}$$
$$M_3 = A_{11}(B_{12} - B_{22})$$
$$M_4 = A_{22}(B_{21} - B_{11})$$
$$M_5 = (A_{11} + A_{12})B_{22}$$
$$M_6 = (A_{21} - A_{11})(B_{11} + B_{12})$$
$$M_7 = (A_{12} - A_{22})(B_{21} + B_{22})$$

* **Recurrence Relation:** $T(n) = 7T(n/2) + O(n^2)$
* **Time Complexity:** By the Master Theorem, this evaluates to $O(n^{\log_2 7}) \approx O(n^{2.81})$

This means for larger dimensions of $n$, Strassen's method will always perform fewer scalar multiplications than the naive triple-loop method.
