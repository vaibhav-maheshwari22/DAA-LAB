# Question 3: Find Maximum and Minimum using Divide & Conquer

## Problem Statement
Design an algorithm to find the maximum and minimum elements in an array of $n$ elements using a Divide and Conquer strategy. The algorithm must restrict the total number of comparisons to at most **$3n/2 - 2$**. Compare this with the naive linear scan method.

---

## Theoretical Justification

### The Naive Approach
In a standard linear scan, we initialize the maximum and minimum to the first element. We then iterate through the remaining $n-1$ elements. In the worst case, each element is compared against the current minimum and maximum, leading to $2$ comparisons per element. 
* Total comparisons: $\approx 2n - 2$

### The Divide & Conquer Approach
The array is recursively divided into two halves until the sub-arrays contain either $1$ or $2$ elements.
* **Base Case 1 ($n=1$):** $0$ comparisons.
* **Base Case 2 ($n=2$):** $1$ comparison (between the two elements to define min and max).
* **Conquer Step:** Combining the results of the left and right halves takes exactly $2$ comparisons (one to compare the minimums, one to compare the maximums).

**Recurrence Relation:**
$$T(n) = 2T(n/2) + 2$$
Using the base cases $T(2) = 1$ and $T(1) = 0$, solving this recurrence relation analytically for $n$ (when $n$ is a power of 2) yields:
$$T(n) = \frac{3n}{2} - 2$$

This proves that the D&C approach mathematically saves approximately $25\%$ of comparisons compared to the naive method.
