# Question 3: Application of sorting-III (K-Sum Problem)

## Problem Statement
Given a set S of n integers and an integer T, give an $O(n^{k-1} \cdot \log n)$ algorithm to test whether k of the integers in S add up to T[cite: 2].

## Approach
This is a generalized k-sum problem optimized using **Sorting and Recursion**:
1. Sort the array $S$ in $O(n \log n)$ time.
2. Use a recursive sweep to fix $(k-1)$ elements. This requires $(k-1)$ nested loops (handled via recursion), yielding an $O(n^{k-1})$ time factor.
3. For the final $k^{th}$ element, instead of looping, perform an $O(\log n)$ Binary Search in the remaining suffix of the array for `Target - Sum_of_fixed_elements`.
4. Overall time becomes the combination of the outer loops and inner search: $O(n^{k-1} \cdot \log n)$.

## Time and Space Complexity
* **Time Complexity:** $O(n^{k-1} \log n)$ — As required by the problem mathematically.
* **Space Complexity:** $O(k)$ — Stack space for recursion depth and the array used to store the valid combination.
