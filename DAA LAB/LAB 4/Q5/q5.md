# Question 5: Application of sorting-V (Merge Overlapping Intervals)

## Problem Statement
Given a list I of n intervals, specified as $(x_i, y_i)$ pairs, return a list where the overlapping intervals are merged[cite: 2]. For $I = \{(1, 3), (2, 6), (8, 10), (7, 18)\}$ the output should be $\{(1, 6), (7, 18)\}$[cite: 2]. Your algorithm should run in worst-case $O(n \cdot \log n)$ time complexity[cite: 2].

## Approach
To efficiently merge intervals, we process them sequentially:
1. Sort all intervals based on their **start times** using `qsort()` in $O(n \log n)$ time.
2. Initialize a dynamic array to store the merged intervals and push the first interval into it.
3. Iterate through the sorted intervals. If the start time of the current interval is $\le$ the end time of the last merged interval, an overlap exists. Update the end time of the last merged interval to the maximum of both end times.
4. If no overlap exists, simply append the current interval to the merged list.

## Time and Space Complexity
* **Time Complexity:** $O(n \log n)$ — Sorting the intervals. The merge pass takes only $O(n)$ time.
* **Space Complexity:** $O(n)$ — For the auxiliary array storing the final merged intervals.
