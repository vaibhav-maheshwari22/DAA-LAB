# Q1 — Online Graph-Bipartiteness Testing

**File:** `q1.c`

## Problem

Process an undirected graph's edges as they arrive. Accept an edge only if the resulting graph remains bipartite.

## Input

- First line: $V$ and $E$.
- Each following line: edge $u$ $v$, with vertices numbered $0$ to $V-1$.

## Output

- Per edge: whether it is `accepted` or `skipped` (violates bipartiteness).
- Final line confirming the graph remains bipartite.

## Approach

Maintain a **parity DSU**: each vertex stores its colour parity relative to its component root. Two vertices may be joined by an edge only if their parities differ; equal parities within the same component would create an odd cycle.

$$
\text{parity}[u] \oplus \text{parity}[v] = 1
$$

When merging two components, the new edge's parity relation is propagated:

$$
\text{parity}[\text{child}] = \text{parity}[u] \oplus \text{parity}[v] \oplus 1
$$

Path compression updates each vertex's parity to its ultimate root on `find()`.

## Complexity

- **Time:** $O(E\, \alpha(V))$ — each edge performs a constant number of DSU operations.
- **Space:** $O(V)$ — parent, size, and parity arrays.
