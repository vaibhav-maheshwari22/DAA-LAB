# Q2 — Dynamic Connected Components in a Grid

**File:** `q2.c`

## Problem

An $R \times C$ grid starts as all water. Land cells are added one at a time. Report the number of 4-directionally connected land components after each addition.

## Input

- First line: $R$ $C$ $k$ (rows, columns, operations).
- Next $k$ lines: zero-based coordinates $r$ $c$ for each land addition.

## Output

- Island count after each operation, space-separated on one line.

## Approach

Flatten $(r, c)$ to a 1D index $r \cdot C + c$ and maintain a DSU over all cells. When a cell becomes land:

1. Mark it active, initialise its size to $1$, increment the island counter.
2. For each of its 4 neighbours that is already land, union the two cells. Every successful union decreases the count by one.

$$
\text{islands} \gets \text{islands} + 1 - \#\{\text{successful unions with land neighbours}\}
$$

Duplicate additions are no-ops — the count stays the same.

## Complexity

- **Time:** $O(k\, \alpha(R C))$ — at most 4 DSU unions per operation.
- **Space:** $O(R C)$ — parent and size arrays for all cells.
