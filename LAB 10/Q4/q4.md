# Q4 — Reverse Time-Step DSU Application

**File:** `q4.c`

## Problem

A vertex-weighted undirected graph loses vertices one by one in a given order. After each deletion, report the maximum total vertex weight among the remaining connected components.

## Input

- First line: $V$ $E$.
- Second line: $V$ vertex weights.
- Next $E$ lines: edge endpoints $u$ $v$.
- Last line: $V$ integers — the deletion order $p_1, p_2, \ldots, p_V$.

## Output

- Maximum remaining component weight after each deletion, one per line.
- Print $0$ if no vertices remain.

## Approach

Deletions split components — hard to handle forward. Process the deletion order in **reverse** instead, so each step becomes an **insertion** of a vertex and its incident edges, which DSU handles in $O(\alpha(V))$.

Maintain $\text{total}[r]$ as the sum of active vertices in the component rooted at $r$. Before each reverse insertion, scan active roots to record the current maximum — this is exactly the state *after* the corresponding forward deletion.

$$
\text{total}[r] = \sum_{v \in \text{component}(r)} w_v
$$

## Complexity

- **Time:** $O(V^2 + E\, \alpha(V))$ — one $O(V)$ scan per reverse step, plus DSU unions.
- **Space:** $O(V + E)$ — adjacency lists, DSU state, saved answers.
