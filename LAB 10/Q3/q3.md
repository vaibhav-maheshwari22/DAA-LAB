# Q3 — Maximum Weight Component with Size Constraint

**File:** `q3.c`

## Problem

A vertex-weighted graph receives edges one at a time. After each edge, find the maximum total vertex weight among all connected components whose size does not exceed $K$.

## Input

- First line: $V$ $E$ $K$.
- Second line: $V$ vertex weights.
- Next $E$ lines: edge endpoints $u$ $v$, vertices numbered $0$ to $V-1$.

## Output

- After each edge: the best qualifying component weight, or `NONE` if no component qualifies.

## Approach

DSU tracks two aggregates per component root:

$$
\text{size}[r] = |\text{component}(r)|, \qquad \text{total}[r] = \sum_{v \in \text{component}(r)} w_v
$$

After each union, scan all roots and pick the maximum $\text{total}[r]$ among components with $\text{size}[r] \le K$:

$$
\text{best} = \max_{r:\ \text{size}[r] \le K} \text{total}[r]
$$

## Complexity

- **Time:** $O(E\,(V + \alpha(V)))$ — one $O(V)$ root scan per edge.
- **Space:** $O(V)$ — DSU arrays and vertex weights.
