# Q5 — Lexicographically Smallest Connected Component Permutation

**File:** `q5.c`

## Problem

Given a permutation $A$ of $1 \ldots n$ and a set of allowed swaps $(u, v)$, find the lexicographically smallest permutation reachable through any number of swaps.

## Input

- First line: $n$ $m$.
- Second line: the permutation $A_1 \ldots A_n$.
- Next $m$ lines: swappable index pairs $u$ $v$, numbered $0$ to $n-1$.

## Output

- The lexicographically smallest achievable permutation, space-separated.

## Approach

Positions connected by a chain of allowed swaps form an equivalence class; the values inside each class can be permuted arbitrarily. DSU groups these positions.

For each component, sort positions and values independently, then assign in order:

$$
\text{answer}[p_k] = v_k
$$

where $p$ and $v$ are the component-sorted positions and values. This greedy is optimal: placing the smallest value at the smallest available position minimises the prefix of $A$ at every step.

## Complexity

- **Time:** $O((n + m)\, \alpha(n) + n \log n)$ — DSU grouping plus per-component sorts.
- **Space:** $O(n)$ — DSU, position, value, and output arrays.

## Compile and Run

```bash
gcc -std=c99 -Wall -Wextra q5.c -o q5
./q5
```

## Sample

Input:
```
2 1
2 1
0 1
```

Output:
```
1 2
```

1. Edge $(0,1)$ unions indices $0$ and $1$ → single component with root $0$.
2. Positions in the component: $\{0, 1\}$. Values in the component: $\{2, 1\}$.
3. Sorted positions: $0, 1$. Sorted values: $1, 2$.
4. Assign: $\text{answer}[0] = 1$, $\text{answer}[1] = 2$ → **`1 2`**.

## Note

Components are independent — no swap ever moves a value across components. This is why per-component sorting is sufficient for global lexicographic minimality.
