# Question 1: Application of sorting-I (Stable Color Sort)

## Problem Statement
Assume that we are given n pairs of items as input, where the first item is a number and the second item is one of three colours (red, blue, or yellow)[cite: 2]. Further assume that the items are sorted by number[cite: 2]. Give an $O(n)$ algorithm to sort the items by colour (all reds before all blues before all yellows) such that the numbers for identical colours stay sorted[cite: 2]. 

## Approach
Since standard $O(n)$ sorting algorithms (like the Dutch National Flag 3-way partition) are not stable and will disrupt the relative order of the numbers, we use an **$O(n)$ Bucket-based Stable Sort**.
1. Create three separate dynamic arrays (buckets) for `RED`, `BLUE`, and `YELLOW`.
2. Traverse the original array in $O(n)$ time. Since the original array is already sorted by number, pushing items into their respective color bucket inherently preserves this sorted order.
3. Reconstruct the array by copying back elements from the `RED` bucket, then `BLUE`, and finally `YELLOW`.

## Time and Space Complexity
* **Time Complexity:** $O(n)$ — Single pass to distribute, single pass to reconstruct.
* **Space Complexity:** $O(n)$ — Auxiliary memory required for the three temporary buckets.
