# Question 2: Application of sorting-II (Two Set Target Sum)

## Problem Statement
Given two sets $S_1$ and $S_2$ (each of size n), and a number $x$, describe an $O(n \cdot \log n)$ algorithm for finding whether there exists a pair of elements, one from $S_1$ and one from $S_2$, that add up to $x$[cite: 2]. 

## Approach
A brute-force approach requires checking every pair, taking $O(n^2)$ time. We optimize this to $O(n \log n)$ using **Sorting + Binary Search**:
1. Sort the second set $S_2$ in ascending order using `qsort()`, which takes $O(n \log n)$ time.
2. Iterate through each element $y$ in $S_1$.
3. For each $y$, compute the required counterpart `required = x - y`.
4. Perform an $O(\log n)$ Binary Search for `required` in the sorted $S_2$.
5. If found, the pair exists. The total time for $n$ binary searches is $n \cdot O(\log n) = O(n \log n)$.

## Time and Space Complexity
* **Time Complexity:** $O(n \log n)$ — Dominated by sorting $S_2$ and the $n$ binary searches.
* **Space Complexity:** $O(1)$ — Auxiliary space (excluding the memory used to store the sets themselves).
