# Question 6: Application of sorting-VI (Point in Maximum Intervals)

## Problem Statement
You are given a set S of n intervals on a line, with the $i^{th}$ interval described by its left and right endpoints $(l_i, r_i)$[cite: 2]. Give an $O(n \cdot \log n)$ algorithm to identify a point p on the line that is in the largest number of intervals[cite: 2]. You can assume an endpoint counts as being in its interval[cite: 2].

## Approach
Similar to identifying peak party attendance, we use a **Sweep-line Algorithm**, with a slight modification for inclusive endpoints:
1. Every left endpoint $l_i$ is a `+1` event (interval starts), and every right endpoint $r_i$ is a `-1` event (interval ends).
2. Sort all $2n$ endpoints. 
3. **Crucial Condition:** If a left endpoint and a right endpoint share the exact same coordinate, the left endpoint (`+1`) MUST be processed first because endpoints count as being inside the interval.
4. Sweep through the sorted events, calculate the running sum, and track the coordinate that hits the highest sum.

## Time and Space Complexity
* **Time Complexity:** $O(n \log n)$ — Sorting the $2n$ endpoint events.
* **Space Complexity:** $O(n)$ — Memory required to store the $2n$ events.
