# Question 4: Application of sorting-IV (Party Peak Attendance)

## Problem Statement
A camera at the door tracks the entry time $a_i$ and exit time $b_i$ (assume $b_i > a_i$) for each of n the persons $p_i$ attending a party[cite: 2]. Give an $O(n \cdot \log n)$ algorithm that analyses this data to determine the time when the most people were simultaneously present at the party[cite: 2]. Assume that all entry and exit times are distinct (no ties)[cite: 2].

## Approach
We model this using a **Sweep-line Algorithm**:
1. Flatten the intervals into individual events. An entry is tracked as a `+1` event, and an exit is tracked as a `-1` event.
2. Store all $2n$ events in a single array and sort them based on the timestamp in $O(n \log n)$ time.
3. Linearly traverse the sorted events, maintaining a running sum (current number of people).
4. Track the absolute maximum of this running sum and the timestamp at which it occurred.

## Time and Space Complexity
* **Time Complexity:** $O(n \log n)$ — Sorting the $2n$ events dominates the time cost.
* **Space Complexity:** $O(n)$ — Memory required to store the $2n$ timestamp events.
