# Question 1: Invert the Coin-Triangle

## Problem Statement
Consider an equilateral triangle formed by closely packed pennies or identical coins (centers at points of an equilateral triangular lattice)[cite: 2]. Design an algorithm to flip the triangle upside down in the minimum number of moves if on each move one coin can be slid to a new position at a time[cite: 2]. Give a compact formula for the minimum moves, write a C program to validate your procedures, and derive the complexity analysis[cite: 2].

---

## Mathematical Derivation
1. **Total Number of Coins ($T_n$):**
   For a packed equilateral triangle with $n$ rows, the total number of coins corresponds to the $n$-th triangular number:
   $$T_n = \sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

2. **Equivalence to Maximum Lattice Overlap:**
   Flipping the triangle upside down using the fewest moves is equivalent to superimposing an inverted triangle of size $n$ over the original upright triangle such that their intersection (stationary coins) is maximized:
   $$\text{Minimum Moves } M(n) = T_n - \max |T_{\text{upright}} \cap T_{\text{inverted}}|$$

3. **Compact Formula:**
   The optimal overlap between an upright equilateral triangle of side $n$ and an inverted equilateral triangle of side $n$ preserves an internal hexagon/sub-triangle lattice of points. The maximum number of stationary elements retained is:
   $$\text{Preserved Coins} = \frac{n(n+1)}{2} - \left\lfloor \frac{n(n+1)}{6} \right\rfloor$$
   Therefore, the minimum number of coins that must be moved is:
   $$M(n) = \left\lfloor \frac{n(n+1)}{6} \right\rfloor$$

4. **Validation for Given Lattice ($n = 4$):**
   $$T_4 = \frac{4 \times 5}{2} = 10 \text{ coins}$$
   $$M(4) = \left\lfloor \frac{4 \times 5}{6} \right\rfloor = \left\lfloor \frac{20}{6} \right\rfloor = 3 \text{ moves}$$

---

## Complexity Analysis
* **Time Complexity:** $\Theta(1)$. Evaluating the closed-form equation requires constant time arithmetic operations.
* **Space Complexity:** $\Theta(1)$. Computations are performed using scalar registers without auxiliary memory allocation.
