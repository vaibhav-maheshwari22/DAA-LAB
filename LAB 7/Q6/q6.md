# Question 6: The Best Time to Be Alive

## Problem Statement
An editor wants to identify the year when the largest number of prominent scientists were alive. The input consists of each scientist's birth and death years. If person A died in the same year person B was born, person A's death is assumed to have occurred before person B's birth. Devise an algorithm, implement it in C, and derive its time and space complexity.

---

## Algorithm & Implementation Strategy

### 1. Sweep-Line Transformation
Each scientist's lifespan $[B_i, D_i]$ is decomposed into two distinct point events along a 1D timeline:
* **Birth Event:** $(\text{year} = B_i, \text{type} = +1)$
* **Death Event:** $(\text{year} = D_i, \text{type} = -1)$

### 2. Tie-Breaking Guarantee
When a birth and a death coincide in the same year ($B_j = D_i$), the problem specifies that the person who died does not overlap with the newly born person.
* By assigning $\text{type} = -1$ to deaths and $\text{type} = +1$ to births, a comparator sorting by year ascending, then by type ascending will naturally process the departure ($-1$) before the arrival ($+1$).

### 3. Chronological Sweep
After sorting the $2n$ events, a single linear sweep tracks the prefix sum of `type`:
$$\text{alive}(t) = \text{alive}(t-1) + \text{event}[i].\text{type}$$
Whenever `alive(t)` strictly exceeds the previous maximum, the current year and count are recorded as the optimal candidate.

---

## Complexity Analysis
* **Time Complexity:** $O(n \log n)$, dominated by sorting $2n$ timeline events using Quick Sort (`qsort`). The subsequent sweep-line pass runs in linear $O(n)$ time.
* **Space Complexity:** $O(n)$ auxiliary memory to store the array of $2n$ event structures.
