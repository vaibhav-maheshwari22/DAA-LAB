# Question 4: Heap Sort with File I/O

## Problem Statement
Implement Heap Sort to sort N randomly generated elements stored in a file. Do the complexity analysis of your algorithm.

## Approach & Features
1. **Random Generation:** Generates $N$ random numbers and writes them to `input_hs.txt`.
2. **File Reading:** Reads the unsorted integers back from the disk into a dynamically allocated array.
3. **Heap Sort:** 
   * First, transforms the array into a Max-Heap in $O(N)$ time.
   * Then, iteratively extracts the maximum element, swaps it to the end of the array, and re-heapifies the remaining structure in $O(\log N)$ time per element.
4. **Validation:** Checks if the final in-memory array is strictly ascending before writing to disk.
5. **Output Export:** Writes the verified sorted data to `output_hs.txt`.

## Complexity Analysis
* **Time Complexity:** $O(N \log N)$ in **all cases** (Best, Average, and Worst). Building the heap takes $O(N)$ time, and extracting $N$ elements takes $O(N \log N)$ time.
* **Space Complexity:** $O(1)$ auxiliary space. Heap sort operates entirely in-place without needing extra arrays or deep recursion stacks.
